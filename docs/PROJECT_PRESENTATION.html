PROJECT PRESENTATION

🍰 Sweet County Bakery

An Artisanal Full-Stack E-Commerce Platform with 3D Product Spotlights & Animated Packing

  • Live Production Web App: https://sweet-county.vercel.app

SYSTEM ARCHITECTURE

🏗️ Single-Domain Full-Stack Architecture

The entire application is unified on Vercel under one domain (sweet-county.vercel.app). Requests to /api/* are handled serverlessly with 0ms cross-server latency.

  • Client UI Layer: React 19 single-page application with client-side state management (Cart & Auth Context).
  • Serverless API Layer: Native Vercel Serverless Function (api/index.js) processing auth, catalog, cart, and payment routes.
  • SPA Navigation Rewrite: Catch-all fallback routing in vercel.json ensuring direct loads on /cart or /store never fail.

KEY FEATURES

✨ Interactive 3D Features & Checkout

  • 3D Levitating Cake Spotlight: Mouse-tilt interactive container with floating mid-air cake motion and floating orbital sparkles.
  • 3D Bakery Box Packing Animation: Interactive sequence before checkout where the cake drops into a branded box, seals with a lid, wraps in a satin ribbon, and stamps with a wax seal.
  • Razorpay Payment & COD: Interactive test modal supporting UPI QR (GPay, PhonePe, Paytm), Credit/Debit Cards, Netbanking, and Cash on Delivery.
  • Admin Dashboard & User Database: Live order status management and registered customer account viewer.

TECHNICAL SOLUTIONS

🚧 Challenges Faced & Resolved

# Challenge Technical Fix
1 Connection Error ("Could not connect to server") Unified Frontend and Backend onto Vercel Serverless Functions (api/index.js).
2 500 Serverless Execution Error Converted api/index.js to ES Module format (export default handler).
3 404 Error on Direct Page Load (e.g. /cart) Configured SPA catch-all rewrite in vercel.json to route requests to /index.html.
